# Add inspection status lifecycle and block unsafe sign-off

Ticket: INS-142

## Problem

Staff can open an inspection. They cannot see if it is scheduled, completed, or cancelled.
An inspector can also sign off an inspection when a required safety check is not done.

## Acceptance

1. An inspection has a status of SCHEDULED, COMPLETED, or CANCELLED.
2. Existing seed inspections get a sensible status.
3. The status shows on the facility and inspection pages.
4. An inspector cannot mark an inspection COMPLETED if any required safety check is not done. The app shows a clear error.
5. A CANCELLED inspection cannot be completed.
6. Messages exist in all message files.
7. There are tests for each rule.
